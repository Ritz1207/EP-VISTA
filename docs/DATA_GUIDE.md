# 数据与跨项目型号库

首次安装见 [README](../README.md)，完整操作流程与计算口径见 [使用指南](USER_GUIDE.md)。

CSV是一张带列名的表，JSON是一份分组保存的设置单。日常编辑推进器不需要手改这两种文件，直接使用“候选推进方案”栏顶部的“推进器型号库”按钮。

## 名称约定

| 名称 | 含义 |
|---|---|
| 项目 | 可保存、打开的一组任务设置和候选方案 |
| 任务 | 项目中分析的卫星任务，例如任务设计寿命、轨道和功率要求 |
| 推进器型号库 | 可供多个项目使用的共享型号记录，简称“型号库” |
| 候选推进方案 | 当前项目中已载入或自建、可勾选参与计算的方案 |

“导入CSV”是把外部文件合并到型号库；“载入本项目”是从型号库加入候选方案；“收录本项目方案”则是反向保存到型号库。三者不是同一操作。物理术语“工程模型”“工程输入”保持原意；“推功比”统一表示推力与功率之比。

## 哪些文件负责什么

| 文件 | 用途 | 操作方式 |
|---|---|---|
| data/thrusters/thrusters.csv | 跨项目推进器型号库，统一保存ID、推进器类型、推进方式、性能、默认结构质量、来源和计入范围 | 型号库中新增、编辑、删除、导入、导出 |
| data/space_weather/*.csv | 太阳与地磁活动历史输入，不是大气密度数据库 | 项目中选择“历史数据CSV” |
| 天气同目录的 *_manifest.json | 来源、原始文件哈希、覆盖范围、质量标记统计 | 溯源查看，不作为数值模型输入 |
| examples/new_project_template.ep-vista.json | 启动时的新项目模板，必填项有意留空 | 通过界面填写并另存 |
| examples/battery_mass_demo.ep-vista.json | 100小时示例任务 | 用“打开项目”，不是型号库导入 |
| workspace/projects/*.json | 用户项目：任务、候选参数快照、本项目质量和自定义方案 | 保存/打开项目；不随源码提交 |
| workspace/library_backups/*.csv | 每次修改型号库前的完整备份 | 需要恢复时，退出程序后取对应备份恢复工作CSV |
| 以前报告目录的JSON、CSV、PNG、HTML | 历史版本生成的结果文件 | 原件保留；当前版本已移除报告导出，不再生成这些文件 |

性能与默认结构质量保存在同一 CSV 中，但来源字段分开记录，防止把“用户近似质量”误认为文献测量结果。

型号库编辑直接修改 `data/thrusters/thrusters.csv`，备份才进入 `workspace/library_backups/`。发布或提交前需要检查该 CSV 是否混入个人记录；忽略 `workspace/` 不会隐藏型号库本身的改动。

V1.0冻结时，仓库内当前`data/thrusters/thrusters.csv`已由著作权人确认为正式公开基准。此后通过GUI产生的新修改不会自动成为后续公开基准，仍须在下一版本冻结时重新核对。

## 型号库与项目的关系

型号库是本套EP-VISTA目录内的共享资源，不属于某个项目。在项目A收录一条记录，项目B可以从同一型号库中载入。不同电脑或不同程序目录，通过导出/导入CSV交换；当前没有云同步或多人服务。

界面统一称“推进器型号库”。新建项目候选表为空，打开型号库不会自动添加候选；选中型号并点击“载入本项目”后才加入。已有项目按其保存的候选参数快照恢复。型号库是独立窗口，没有结果页的四个选项卡；关闭后可从候选栏重新打开。

从2.2格式起，保存项目会保留推进器参数快照 library_snapshot，自定义方案保存在 custom_thrusters；本项目质量及来源保存在 propulsion_structure。2.3格式在候选快照中增加推进器类型。编辑、改ID或删除型号库记录不会自动替换已保存项目，只有明确“载入本项目”才更新对应记录。

旧2.0/2.1项目若没有参数快照，首次打开时用当时型号库补齐；2.2及更早项目缺少推进器类型时按“其他”兼容读取。下一次保存升级为2.3。原文件不会因打开而被改写。程序无法凭旧项目中仅有的ID恢复已经丢失的历史性能版本，应核对后另存。旧项目中明确保存的质量覆盖仍然保留。

补齐旧项目时，自定义方案优先：与其同ID的公共型号不会再被重复加入。如果项目已经显式保存了两份同ID方案，程序不擅自选择或丢弃参数；可在候选表中逐行核对，用“移除选中方案”去掉多余行。重复ID会在启动计算前提示。

项目快照解决推进器参数随库变化的问题，不包含天气CSV本体。发送项目给别人时仍须一并提供所用天气文件，并重新选择其路径。结果窗口和高度扫描使用该次运行快照。报告导出已移除，型号库的CSV导出不受影响。

## 日常操作

1. 在“候选推进方案”栏顶部点击“推进器型号库”，不必先计算。输入窗口顶部不再放置此按钮。
2. 点击“新增记录”，填写不重复的ID，并选择推进器类型（霍尔、离子或其他）。选择“其他”后可以填写具体类型。推进方式另选“传统供质”或“吸气式ABEP”，两者不是同一字段。
3. 双击已有记录或点击“编辑记录”可修改ID、类型、性能、工作范围、默认结构质量及来源；修改ID不会更新已有项目中的旧ID快照。每次保存旧CSV都会自动备份。
4. 选中记录并点击“删除选中记录”可从型号库删除；确认后自动备份，已有项目不变。型号库至少保留一条记录。
5. 选中一条或多条记录，点击“载入本项目”。若与项目同ID，会确认是否一起覆盖性能和质量；载入后需保存项目、重新计算。
6. 如已在项目中建立了自定义方案或修改了质量：在候选表点选目标行，直接点击同栏顶部的“收录本项目方案”。此按钮与“推进器型号库”并列，不在型号库窗口内。它收录当前选中行，不是全部勾选项；未选中行时按钮不可用。
7. “刷新”只重读公共型号库，不改项目。另一窗口已修改型号库时，旧窗口保存会被阻止，需刷新后重新编辑。
8. “导出CSV”导出完整型号库；“导入CSV”先校验并显示记录数、未知质量数及同ID冲突，确认后合并，同ID冲突采用导入版本。

在候选表修改质量只作用于当前项目；只有显式收录才更新公共默认值。质量空白=未知，0=明确未计入，不是同一意思。质量范围须自行核对是否包括PPU、储箱、进气装置等。

## 移除本项目候选方案

点击候选表中的目标行，再点击表格下方“移除选中方案”，确认后移除。它既适用于自定义方案，也适用于从型号库载入的方案；取消确认不作更改。

- 移除仅针对当前选中行，不是所有勾选行；同ID的两行也可以分别移除。
- 不删除型号库记录、其他项目或已有结果；未收录的自定义方案请先保存副本或收录，再移除。
- 最后一条同ID候选移除后，同时清除其本项目质量设置和无效质量标记。剩余方案与其勾选状态保留。
- 保存项目后移除结果才写入文件，重新打开不会自动从型号库补回；需要时可以重新载入。
- 取消勾选只是本次不计算，仍保留该候选；“移除”才是从项目中去掉。全部移除后可以保存空项目，但不能运行计算。
- 已完成的结果和高度扫描继续使用原计算快照；移除后若需更新结果，必须重新计算。

原有 ENG_ABEP20 工程假设记录仍保留在底层CSV，并随完整型号库CSV导出保留，但继续沿用原界面的隐藏规则；型号库窗口显示其余默认记录和用户新增的型号，项目候选表只显示已载入或随项目恢复的方案。

## CSV导入约定

优先先导出型号库，用导出的表头作为批量整理模板。普通新增用表单即可。

必需列为 thruster_id、name_zh、architecture、propellant、thrust_to_power_mN_kW、isp_s。architecture 是推进方式，值为 traditional 或 abep；thruster_type 是推进器类型，可写霍尔、离子或用户自定义文字。功率单位kW、推功比mN/kW、比冲s、结构质量kg；不同功率口径必须写明。

其余列可以省略，推荐保留完整表头。旧CSV没有thruster_type时仍可读取：程序按已知名称识别HET/TAL/BHT/PPS为霍尔，NEXT/NSTAR等为离子，其他按“其他”；读取不会重写原文件，后续保存前应人工核对。缺少结构质量时按未知处理，不再另外寻找质量JSON。未知列名、重复ID、重复列名、列数错位、非有限数值、负质量、不合理功率上下限或效率会拒绝导入。导入的同ID未知质量也会覆盖原默认质量，须留意确认提示。

性能来源列为 source、locator、notes；质量列为 structure_mass_kg、structure_mass_source、structure_mass_notes。保留 data_type、power_basis、metric_coincidence 和 verification_status 可追溯证据类型与核验状态。表单录入/编辑的记录标为 user_input，不冒充已验证文献数据。

当前导入必须符合本项目列名和单位，尚无任意Excel文件导入、列名映射、单位自动转换或性能曲线数据库。

## 空间天气

在天气区域选择“历史数据CSV”，再选择文件。这是读取已有数据，不是自动下载或转换任意网站原表。

| 字段 | 含义 |
|---|---|
| utc | 带UTC时区，00、03、06等整三小时对齐且连续 |
| f107_previous_day_sfu | 前一日F10.7 |
| f107_centered_81day_sfu | 中心81日均值，不是后向81日均值 |
| ap_daily | 当日平均Ap |
| ap_current_3h | 当前三小时Ap |
| ap_3h_prior / ap_6h_prior / ap_9h_prior | 前3/6/9小时Ap |
| ap_mean_12_33h / ap_mean_36_57h | 对应历史区间Ap均值 |
| interpolated_or_predicted | 0或1的质量标记，不是许可状态 |

数据须覆盖整个任务及起始一圈采样；原始序列须有足够前后数据以计算上述历史与中心均值。格式校验不代替来源与数据质量核查。

随附历史天气CSV含3335行，记录时间为2025-03-20 00:00 UTC至2026-05-10 18:00 UTC，其中7行带插值/预测标记。来源、哈希和引用见[数据来源与引用](DATA_SOURCES.md)。

天气输入按文件选择，当前没有统一天气库、自动下载器或“我的数据”页面。
