# 源码发布检查清单

本清单供维护者在每次独立 GitHub 源码发布前使用。许可证文件已落实，但随附数据仍有来源与再分发核查事项；文档、配置或测试通过不代表已经完成公开发布。

## 已确定的发布策略

- 自研程序采用AGPL-3.0-or-later，根目录LICENSE保留官方原文；不限制自研程序只能用于学术或非商业用途。
- [ADDITIONAL_PERMISSION.md](../ADDITIONAL_PERMISSION.md) 仅处理与未修改NRLMSIS 2.0经pymsis 0.12.0的源码分发和互操作。自研代码修改仍受AGPL约束，不授予模型或其他第三方权利。
- GitHub仅发布自研源码、必要文档/配置及经核查的数据；不分发NRL模型源码、二进制、EXE、完整环境或容器。依赖由使用者按原许可另行获取。
- 当前NRLMSIS是计算必需依赖，不声称已经实现其他可选大气后端。自研源码开源不等于完整运行环境自由商用。
- 附加许可不涵盖其他模型、接口版本或一般闭源组件；更换依赖版本、增加后端或改变分发方式时，重新核对许可范围。

## 源码发布范围

- 原历史天气CSV及其来源manifest保留；来源与引用集中到[数据来源与引用](DATA_SOURCES.md)，不以合成天气替换。
- 推进器性能和默认结构质量合并为一个CSV；V1.0以当前`data/thrusters/thrusters.csv`的10条记录为正式公开基准，提供跨项目型号库操作，项目保存参数快照。
- data与examples纳入发布审查；workspace中的个人项目、缓存、型号库备份和导出排除。型号库编辑会直接修改data/thrusters/thrusters.csv，须另行核对其记录。
- 模型源码、二进制和完整Python环境不在本目录中；依赖须另行安装。
- 报告导出入口与专用代码已移除；仍支持项目保存、结果查看和型号库CSV导出，已有报告不删除。
- 软件引用同时提供BibTeX、GB/T 7714—2025和MLA格式，CFF保留机器可读元数据；未编造公开仓库URL、DOI或发布日期。
- 软件中文全称、英文全称、简称、V1.0版本和公开署名须与README、`pyproject.toml`、`CITATION.cff`及引用文档一致。软著申请材料属于本地私有材料，不纳入公开仓库、源码归档或GitHub Release；公开开发、维护和引用署名统一使用Ritz。

## 公开前仍需确认

1. **公开文件清单。** 核对实际暂存内容，不上传个人项目、缓存、环境包或密钥。忽略规则不能防止强制添加或手动上传。
2. **来源完整性。** 保留真实天气和推进器数据，并补全尚未核验的性能文献书目。按具体数据来源核对使用与再分发依据；引用本身不构成授权。
3. **NRL模型与组合使用。** 核对上述例外、实际调用版本、源码头与NOTICE一致，且提交内容不含第三方模型或完整环境。额外许可仅来自EP-VISTA作者，未取得额外NRL授权；不把它当作NRL模型商用、修改或再分发许可。商业用途及超出已有许可的情形，须向NRL有权部门确认；本地格式核对不能代替专业法律意见。
4. **许可文件与元数据。** 项目根目录的LICENSE、ADDITIONAL_PERMISSION.md及licenses/中的NOTICE.md、第三方原文必须随源码保留；核对本地LicenseRef定义和相应源码指引。第三方数据不被该标识重新授权，许可证原文不得擅自修改。
5. **发布信息与确认。** 核对目标仓库、公开文件清单、版本标签及 Release 说明。发布内容须经维护者确认；许可证准备、文档整理和测试通过不等于已经执行上传或发布。

## 独立仓库完整性

- [ ] README 从首次获取源码开始说明安装、GUI/CLI 用法、模型边界和求助入口，不引用仓库外的内部归档。
- [ ] GUI 启动模板和演示文件齐全，文档、代码与测试引用一致；空白模板的必填空项不误当作损坏。
- [ ] 在独立目录检查源码运行，保留 src、data、examples 与启动脚本，不依赖外层科研目录。
- [ ] 在新环境验证环境配置与开发依赖安装；记录实际测试过的操作系统，不将本机通过等同于跨平台支持。
- [ ] 公开文档不含无意义的本机路径；来源 manifest 的本机快照位置如需整理，应保留来源 URL、快照标识与哈希，不改动数值数据。兼容旧项目的路径迁移代码需单独评估，不能直接删除。
- [ ] 版本、作者署名、许可文件与引用信息一致；仓库 URL、发布日期和 DOI 仅在真实存在后填写。

## 验证

按照[贡献说明](../CONTRIBUTING.md)运行型号库测试、示例输入检查，并在有权使用模型的环境中运行短算例。核对旧项目加载、保存后参数快照、型号库同ID冲突、导入导出和天气覆盖。

V1.0冻结时的实际环境、命令、结果与未覆盖边界见[V1.0测试证据](release/V1.0_TEST_EVIDENCE.md)。

格式检查、功能回归、数值基线对比与物理验证不是同一件事。任何模型或数据变更都须重新检查，不能将原缓存或旧结果当作新版本验证结论。
