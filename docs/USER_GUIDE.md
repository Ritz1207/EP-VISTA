# EP-VISTA 使用指南

本指南说明界面操作、输入口径与结果解释。首次安装和命令行用法见 [README](../README.md)，型号库及数据格式见 [数据使用说明](DATA_GUIDE.md)。

## 项目模板与演示

- [新建项目模板](../examples/new_project_template.ep-vista.json) 用于 GUI 初始化，设计寿命、部分质量与供电参数有意留空，候选表为空。它可以打开、填写和保存，但未补齐时不能通过运行输入校验。
- [电池与质量演示](../examples/battery_mass_demo.ep-vista.json) 是可运行的 100 h 示例。系统参数为合成算例，天气采用历史输入；它不构成设备推荐或经认证的设计。
- 旧项目可以兼容读取；保存时升级为2.3，写入候选参数快照和推进器类型。首次读取尚无快照的旧项目时，所用型号参数取自当前型号库。

## 界面使用流程

1. 启动后点击“打开项目”，文件选择器会默认进入`examples/`；选择 `battery_mass_demo.ep-vista.json`。它包含100 h任务及合成系统参数，只是演示，不是设备推荐。快速试用可以把任务设计寿命改短。
2. 核对起始UTC、设计寿命、轨道高度和LTAN，以及本体迎风面积、阻力系数、结构质量和载荷质量。
3. 设置整星功率、电推进功率、太阳翼或电池参数。整星功率包含电推进功率。
4. 在“候选推进方案”栏顶部点击“推进器型号库”，进入独立窗口新增、编辑、删除或导入型号；ID、推进器类型、推进方式、性能、默认质量和来源在同一表单中维护。“推进器类型”可选霍尔、离子或自定义的其他类型；“推进方式”区分传统供质与吸气式ABEP。新建项目候选表为空，选中型号后点击“载入本项目”才加入。
5. 运行分析，在独立结果窗口的“任务全程推阻关系”中查看曲线，也可切换到“绕地一周”“高度扫描”和“结论”。吸气式方案的平均推力曲线与推力范围色带分别列入图例，平均口径在图题下单独说明。更改输入后须重新计算；旧结果和高度扫描使用上次运行的输入快照。
6. 保存为 `.ep-vista.json`；未填完整也可以先保存。项目文件保存输入设置，不是计算报告。

项目设置、分析结果和推进器型号库窗口底部均以小字显示 `Copyright © 2026 Ritz · 分析结果仅供参考，请结合模型假设与数据适用范围核验。` 界面使用作者公开署名；署名不替代完整版权和许可说明，具体范围以 [NOTICE.md](../licenses/NOTICE.md) 及其引用的许可文件为准。

报告导出功能已移除，不再生成结果JSON、CSV、PNG或HTML报告。命令行run只计算并在终端显示结论，不再支持--output。项目保存/打开、型号库CSV导入导出仍保留；此前生成的报告文件不会被删除。

关闭结果窗口只隐藏它，可通过“查看结果”重新打开。计算时可取消；关闭设置窗口时若仍在计算，按提示等待当前批次安全结束。旧 `.ept.json` 可以读取，但缺失的新供电/质量参数须手工补齐，旧总质量不自动拆分。

保存项目使用2.3格式，包含候选参数快照及推进器类型；修改、改ID或删除公共型号库记录不会自动改变旧项目。更新项目需显式载入型号库记录。详细操作见[数据使用说明](DATA_GUIDE.md)。

候选表下方“移除选中方案”用于从本项目移除当前行（自定义或载入的型号均可），确认后请保存项目；它不删除型号库或已有结果。取消勾选只是不参与本次计算。旧项目补齐参数时，不再重复加入与自定义方案同ID的公共型号。

## 输入与判断

- 高度支持150–300 km圆形SSO；设计寿命必须由用户输入。
- 历史空间天气CSV必须覆盖整个任务以及起始一圈取样范围，按连续UTC三小时间隔提供前一日F10.7、中心81日均值和七项Ap。默认演示CSV范围为2025-03-20 00:00 UTC至2026-05-10 18:00 UTC。覆盖不足会停止，程序不联网补值。固定低/中/高活动仅为敏感性情景，不是预报。
- 太阳翼单位面积功率W/m²决定面积与发电功率；系统比功率W/kg决定质量，二者不能混用。电池方式允许太阳翼面积为零，但固定硬件面积必须明确填写。
- 电池供电功率=min(整星功率与太阳翼供电差额, 电池输出上限)，差额小于零时按零；配置电量=供电功率×任务时长；电池质量=配置电量/系统级可用比能量。配置电量不是已知实物容量。供电不足时保留理论推进需求，并单独报告功率缺口，不自动降低推进功率。
- 推进方案用“推功比+比冲+功率范围”或同一工作点的“功率+推力+比冲”定义。效率由程序推导，不是第三个独立约束。
- 结构质量空白表示未知，0表示明确未计入。默认型号质量只是用户提供的近似样例，须自行确认PPU、储箱、进气装置等计入范围，避免重复计算。
- `pending_human_verification` 表示参数尚待人工核验，不是已鉴定设备证据。结果不排名、不自动推荐。

“满足任务”指每一圈的时间平均实际可用推力**严格大于**对应平均整星阻力，并满足供电、设备工作范围等条件；相等不算满足。末尾不足一圈按实际经历时段计算。ABEP先逐点取功率和进气限制推力的较小值，再进行逐圈时间平均。该判断允许圈内瞬时推力不足，不代表已验证真实瞬时定高。

“推进系统最低功率”是各圈平均阻力的最大值除以推功比得到的理论阈值，实际功率须超过它，还需满足设备工作范围和ABEP进气条件；它不是设备自身最低工作功率。质量表逐方案合计结构、太阳翼、电池、推进单元、携带推进剂和其他载荷，得到任务初始整星总质量。总冲量由阻力时间积分计算，传统推进剂为总冲量/(比冲×g0)，不是由总质量反算。

高度扫描须主动启动。快速预览每圈约18点，详细计算每圈约72点，表示沿轨道采样密度而非SSO倾角；扫描不同假设轨道，不是同一卫星自然升降。正式使用仍需检查采样收敛。

## 模型边界

采用受控恒定高度圆形SSO、J2长期节点变化、理想对日太阳翼、固定阻力系数和NRLMSIS 2.0。整星阻力包含本体和太阳翼迎风投影。质量变化本身不改变指定几何下的阻力、总冲量和理论推进剂。

不模拟轨道下降、高度波动、大气风场/共转、食期储能、充电循环、进气道详细损失、完整EPS与热设计或设备可靠性/寿命认证。模型与数据来源及许可见 [第三方说明](../licenses/THIRD_PARTY_NOTICES.md)。

## 文件与缓存

仓库根目录是包含启动脚本和 `pyproject.toml` 的目录。以下相对路径均从这里起算：

| 路径 | 用途 |
|---|---|
| `src/`、两个 `run_ep_vista_*.py` 脚本 | 程序源码与 GUI/CLI 启动入口 |
| `data/` | 推进器型号库、历史天气及来源记录 |
| `examples/new_project_template.ep-vista.json` | GUI 启动必需的空白模板 |
| `examples/battery_mass_demo.ep-vista.json` | 可打开和运行的演示项目 |
| `workspace/projects/` | 默认用户项目保存位置，按需创建，不随源码提交 |
| `workspace/library_backups/` | 修改型号库前的备份，不随源码提交 |
| `workspace/cache/`、`__pycache__/` | 运行缓存，可在程序退出后清理 |

移动程序时请完整保留源码和数据目录，不要只复制 Python 模块。相对天气路径从仓库根目录解析；外部天气文件需要在迁移后重新选择。用户保存的项目不包含天气 CSV 本体。

缓存清理后会在下次运行时重新生成，首次计算可能变慢。清理缓存不会替代数据备份；旧版本生成的报告如需保留，应由用户自行保存，当前程序不再生成报告文件。

**型号库修改会写入 `data/thrusters/thrusters.csv`，并非全部进入被忽略的 `workspace/`。** 提交或发布前检查该 CSV 的改动，不要把个人新增记录误当成原始公开样例。

## 常见问题

- **新建项目无法计算：** 空白模板不是完整算例。请填写必填项并载入至少一个候选方案，或先打开演示。
- **提示找不到模板或数据：** 检查是否取得完整仓库；GUI 启动依赖模板，历史模式还依赖指定的天气 CSV。
- **天气覆盖不足：** 核对任务起始 UTC 和设计寿命，并按 [数据说明](DATA_GUIDE.md) 提供覆盖足够时间范围的文件。程序不会自动联网补齐。
- **改过输入但结果没有变化：** 结果与高度扫描使用上次运行的输入快照，修改后需要重新计算。
- **导入 CSV 失败：** 推进器型号库 CSV 与天气 CSV 的结构不同，不能互换；请使用对应入口和列名。

无法解决的问题可按 [贡献指南](../CONTRIBUTING.md) 提供最小复现。界面截图和项目文件请先去除敏感信息。
